# デイサービス（通所介護）看護師向け「機能訓練マニュアル」リサーチ資料

作成日：令和8年7月31日  
目的：看護師（機能訓練指導員）がマニュアルを見ながら安全に加算算定と訓練運用ができる体制の構築

---

## 0. 本マニュアルの前提とエビデンス強度

- **対象事業所**：小規模の通所介護（地域密着型を含む）
- **機能訓練指導員**：看護師（准看護師を含む、以下「Ns」）を雇用予定／PT・OT・STは不在
- **作成方針**：マニュアルを見ながら安全に加算算定と訓練運用が成立することを目標
- **エビデンス強度の凡例**：
  - **【公式】** 厚生労働省通知・関係告示・解釈通知
  - **【学会】** 学会・職能団体が公表する指針
  - **【解説】** 事業者団体・専門メディアによる解説（一次資料と照合済のもの）
  - **【未確認】** 今回の検索で一次資料に到達できなかった項目

> 看護職員による機能訓練には、医師からの指示や対象者の病状把握が必須です。訓練中止基準・緊急時対応は最優先で運用してください。

---

## 1. 法的・制度的根拠

### 1-1. 機能訓練指導員として看護師が算定できる加算の種類

【公式】通所介護ではNsが**機能訓練指導員**として配置要件を満たす場合、以下の加算を算定できます。

| 加算名 | 単位数（2024年度改定後） | Ns単独算定 | LIFE提出 |
|---|---|---|---|
| 個別機能訓練加算（Ⅰ）イ | 56単位/日 | ○ | 不要 |
| 個別機能訓練加算（Ⅰ）ロ | 76単位/日 | ○ | **必要** |
| 個別機能訓練加算（Ⅱ） | 20単位/月 | ○ | **必要**（生活機能チェックシート＋計画書） |
| ADL維持等加算（Ⅰ／Ⅱ） | 30／60単位/月 | ○ | **必要** |
| 生活機能向上連携加算（Ⅰ／Ⅱ） | 100／200単位/月 | **△**（外部PT/OT/STとの共同が必須） | 不要 |
| 口腔機能向上加算（Ⅰ／Ⅱ） | 150／160単位/回（月2回限度） | ○（ⅠのみNsで算定可） | 不要 |

機能訓練指導員になれる職種：理学療法士・作業療法士・言語聴覚士・**看護師・准看護師**・柔道整復師・あん摩マッサージ指圧師・はり師・きゅう師（9資格）

### 1-2. 個別機能訓練加算の算定要件（令和6年度改定後）

#### 個別機能訓練加算（Ⅰ）イ ― 56単位/日
- 機能訓練指導員を1名以上、サービス提供時間を通じて専従で配置
- 個別機能訓練計画の作成とそれに基づく個別訓練の実施
- LIFE提出不要

#### 個別機能訓練加算（Ⅰ）ロ ― 76単位/日
- 機能訓練指導員を2名以上配置（令和6年改定で専従要件が緩和、合計でサービス提供時間を通じて専従していれば足りる）
- **LIFEへのデータ提出が必須**

#### 個別機能訓練加算（Ⅱ） ― 20単位/月
- （Ⅰ）に加えてLIFE提出要件を満たすこと
- 提出書類：興味関心チェックシート・生活機能チェックシート・個別機能訓練計画書・訓練記録

### 1-3. 看護師単独でできること／できないこと

| 区分 | Ns（機能訓練指導員） | PT・OT・ST |
|---|---|---|
| 「機能訓練」（生活行為向上のための訓練） | ○ 可能 | ○ 可能 |
| 「リハビリテーション」（医師の指示に基づく医療行為） | × 不可 | ○ 医師の指示が必要 |
| 個別機能訓練計画書の作成 | ○ | ○ |
| 嚥下機能訓練の手技（直接訓練） | △ リスク評価のみ／本格実施はST・医師判断 | ○ STが専門 |
| ADL訓練 | ○（Nsも実施可） | ○ OTが専門 |

## 2. 機能訓練メニュー（看護師が実施できるもの）

### 2-1. 関節可動域（ROM）訓練
- **目的**：拘縮予防・関節可動域維持
- **対象**：変形性関節症、脳卒中後遺症、廃用症候群、要支援〜要介護3程度
- **内容**：
  - 上肢：肩関節屈伸・内外旋、肘関節屈伸、手指屈伸
  - 下肢：股関節屈伸・内外転、膝関節屈伸、足関節背屈・底屈
  - 体幹：座位での体幹回旋・側屈
  - 1関節5〜10回×2セット、他動→自動介助→activeの順
- **所要時間**：15〜20分/人
- **中止基準**：痛みが増強する、炎症所見（熱感・発赤・腫脹）

### 2-2. 筋力強化訓練
- **目的**：下肢・体幹筋力の維持・向上、転倒予防
- **内容**：
  - 座位での膝伸展（5秒保持×10回）、踵上げ・つま先上げ
  - 椅子からの立ち座り（5〜10回）
  - 座位での骨盤前後傾運動
- **所要時間**：15〜20分/人
- **中止基準**：収縮期血圧160mmHg以上または100mmHg未満、心拍数+30bpm超

### 2-3. バランス訓練
- **目的**：立位バランス改善、転倒予防
- **対象**：TUG≧14秒、転倒既往者
- **内容**：
  - 両脚立位→半歩幅→タンデム立位（段階的に）
  - 支持基底面内での重心移動（前後左右）
  - 座位での上肢リーチ
  - タオルギャザー、ボール足裏転がし
- **所要時間**：10〜15分/人
- **安全確保**：必ず平行棒内・手すり前方・介助者近接で実施

### 2-4. 歩行訓練
- **目的**：歩行能力の維持・改善
- **内容**：平行棒内→歩行器→独歩の段階的実施、障害物回避・段差対応
- **所要時間**：15〜20分/人
- **安全確保**：滑り止め靴、装具は医師確認、FRT15cm未満は常時見守り

### 2-5. ADL訓練（更衣・食事・排泄）
- **目的**：日常生活動作の自立支援
- **内容**：
  - 更衣：前開き上衣から、動作分割
  - 食事：自助具（太柄スプーン・吸盤マット）選定・練習
  - 排泄：下身衣上げ下ろし、洋式トイレ立ち座り
- **所要時間**：20〜30分/人

### 2-6. 呼吸訓練
- **目的**：呼吸効率改善、誤嚥性肺炎予防
- **対象**：COPD、慢性心不全、誤嚥性肺炎既往
- **内容**：口すぼめ呼吸、腹式呼吸、口唇・舌運動
- **所要時間**：10〜15分/人
- **中止基準**：SpO2 90%未満、胸部不快感・呼吸困難

### 2-7. 口腔・嚥下機能訓練
- **目的**：嚥下機能の維持・改善、誤嚥性肺炎予防
- **内容**：
  - パタカラ体操（「パ」「タ」「カ」「ラ」各5〜10回）
  - 舌運動（前後左右、口唇なめ）
  - 頬・口唇運動（ふくらませる・すぼめる）
  - 間接嚥下訓練（唾液嚥下、喉頭挙上）
- **注意**：直接訓練（食物使用）はST・医師の指示下で実施
- **所要時間**：10〜15分/人

## 3. アセスメントと個別計画

### 3-1. 評価ツール

| ツール | 評価領域 | カットオフ目安 | 所要時間 |
|---|---|---|---|
| Barthel Index（BI） | ADL10項目 | 60点以下で中等度依存 | 5〜10分 |
| FIM | 運動13項目＋認知5項目 | 108点未満で介助必要 | 15〜20分 |
| MMSE / HDS-R | 認知機能 | MMSE 23点以下で要精査 | 10〜15分 |
| TUG（Timed Up & Go） | 動的バランス・転倒リスク | 14秒以上で転倒リスク高 | 3〜5分 |
| 片脚立位時間 | 静的バランス | 5秒未満で転倒リスク高 | 2〜3分 |
| RSST（反復唾液嚥下テスト） | 嚥下機能 | 3回未満/30秒で要精査 | 5分 |

※ADL維持等加算は利用開始月と7ヶ月目にBarthel Indexの測定・LIFE提出が必須

### 3-2. 目標設定（SMART原則）

- **長期目標（6〜12ヶ月）**：具体的な生活場面で記述
  - 例：「自宅の廊下を伝い歩きで自立移動できる」
- **短期目標（1〜3ヶ月）**：定量的・期限付き
  - 例：「5m歩行時間を15秒→12秒に短縮（3ヶ月以内）」

### 3-3. 評価・見直しの手順（3ヶ月ごと）

1. 評価項目の再測定（BI・TUG・MMSE等）
2. 本人・家族への説明（書面にて）
3. 短期目標の更新
4. 個別機能訓練計画書の改訂
5. 多職種（介護職・相談員・管理者）への共有

## 4. 記録・書類

### 4-1. 個別機能訓練計画書の必須記載項目（老企第36号準拠）

1. 利用者の基本情報（氏名・要介護度・認定有効期間）
2. 本人の希望・家族の希望
3. 病名、合併疾患リスク、禁忌事項
4. 医師からの指示事項
5. 生活機能評価の結果（興味関心チェックシート含む場合あり）
6. 長期目標・短期目標
7. 具体的訓練内容（メニュー・頻度・所要時間・実施形態）
8. 評価計画と評価時期（概ね3ヶ月ごと）
9. 同意署名（本人または家族）
10. 作成者氏名・作成日

### 4-2. 毎回の訓練記録（SOAP形式）

| 項目 | 記載内容 |
|---|---|
| S（Subjective） | 利用者の主訴・体調訴え |
| O（Objective） | バイタル・訓練内容と回数・実施中の様子 |
| A（Assessment） | 訓練中の反応・計画達成度 |
| P（Plan） | 次回への調整事項 |

最低限：日付・開始時間・訓練内容・バイタル・特記事項・実施者署名

### 4-3. 加算算定に必要な書類一覧

| 加算 | 必要書類 |
|---|---|
| 個別機能訓練加算（Ⅰ）イ | 個別機能訓練計画書＋訓練実施記録 |
| 個別機能訓練加算（Ⅰ）ロ | 上記＋LIFE提出データ |
| 個別機能訓練加算（Ⅱ） | 上記＋興味関心チェックシート・生活機能チェックシート |
| ADL維持等加算 | Barthel Index記録（開始月・7ヶ月目）＋LIFE提出 |
| 口腔機能向上加算 | 口腔機能向上計画書・スクリーニング・アセスメント記録 |
| 共通 | 同意書（個別機能訓練計画書への本人署名） |

## 5. 安全管理

### 5-1. 訓練中止基準（アンダーソン基準・土肥の基準に準拠）

| 観測項目 | OK | 慎重 | 中止・医療者連絡 |
|---|---|---|---|
| 収縮期血圧 | 100〜159 mmHg | 160〜179 / 90〜99 mmHg | 180以上 / 90未満 |
| 拡張期血圧 | 60〜99 mmHg | 100〜109 mmHg | 110以上 |
| 安静時心拍数 | 50〜100 bpm | 101〜119 bpm | 120以上 / 40未満 |
| SpO2 | 95%以上 | 92〜94% | 91%以下 |
| 体温 | 36.0〜37.5℃ | 37.6〜37.9℃ | 38.0℃以上 |
| Borg指数 | 11以下 | 13 | 15以上 |
| 症状 | なし | 軽度息切れ・発汗 | 胸痛・強い動悸・意識変容・めまい |

### 5-2. 転倒リスク評価

- TUG ≧14秒 / FRT 15cm未満 / Berg Balance Scale 45点以下 → 高リスク
- 直近6ヶ月の転倒既往 → 重要リスク指標
- 対応：手すり設置・滑り止め・照明確保・高リスク者は人員厚い時間帯に訓練

### 5-3. 緊急時対応手順

1. 安全確保（転倒時は無理に起こさない）
2. 意識・呼吸・循環の確認（JCS・SpO2）
3. 必要時 119番通報
4. 配置医・協力医療機関への連絡
5. 家族への連絡
6. 事故報告書の作成・行政報告
