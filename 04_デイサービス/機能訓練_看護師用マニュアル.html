機能訓練　看護師用マニュアル

デイサービスセンターこはる日和　／　作成日：2026年8月13日（改訂：全種目 座位化）　／　「機能訓練表」を基に作成
1. 目的・このマニュアルのねらい
歩行の安定・転倒予防・下肢筋力の維持を目的に、短時間（1回 約5〜10分）の機能訓練を日々の中で行います。
このマニュアルは、看護師が①流れを回せる ②各運動を利用者にお手本として見せられる（デモできる）ことを目標にしています。運動は「機能訓練表」の3区分・全11種を用います。
全11種すべて、イスに座ったまま安全に実施できるよう設計しています（立位運動なし）。
2. 実施の流れ（1回 約5〜10分）
1
体調確認・声かけ
「今日の調子はいかがですか」と声をかけ、痛み・気分・（必要なら）血圧を確認。痛みや体調不良があれば無理に行わない。
2
メニューを見せる
3つの区分（可動域・筋力・転倒予防）の運動カード／一覧を利用者に見せる。
3
利用者に選んでもらう
各区分から1つずつ＝合計3種を、利用者自身に選んでもらう。「今日はどれをやってみましょうか？」——選ぶこと自体が意欲につながり、飽き防止になる。
4
看護師がお手本（デモ）
まず看護師が実際にやって見せる。カタログの「デモのコツ・声かけ例」を使う。
5
一緒に実施
各運動 60〜90秒を目安に一緒に行う。声かけ・見守りをしながら、回数やレベルを利用者に合わせる。
6
称賛・記録
「よくできました」と称賛。実施した種目・回数・様子・痛みの有無を記録する。
3. 「選んでもらう」で飽きさせない
メニューを看護師が一方的に決めるのではなく、利用者に各区分から1つずつ選んでもらうのがポイントです。
・自分で選ぶ＝意欲・主体性につながり、続けやすい。
・毎回ちがう組み合わせになりマンネリ・飽きを防ぐ。
・「今日はどれにしますか？」と会話のきっかけにもなる。
※ 選べない・迷う方には、前回と違うものを看護師が2〜3個に絞って提示し、その中から選んでもらうとスムーズです。
4. 機能訓練カタログ（全11種・やり方とデモのコツ）
① 関節可動域運動（準備運動）
R1ロール運動10往復めやす
ねらい股関節・膝・足首を同時に動かし、自然に近い形で関節をほぐす（本運動の前の準備）。
準備するものロール（丸めたバスタオルや専用ロール）
やり方
  1. 仰向けに寝てもらう
  2. 踵の下にロールを置く
  3. 足の裏全体でロールを前後に転がす
  4. これを繰り返す
デモのコツ看護師が自分の足で「足裏全体で押して転がす」を見せる。足首だけでなく脚全体が動くのを示す。
声かけ例「かかとの下の棒を、足の裏でコロコロ転がしましょう」
よくある間違い足が左右にブレる → 「まっすぐ前後だけ」と手を添えて誘導。
注意股関節の人工関節術後の方は屈曲角度により避ける。
レベル調整踵の位置を遠くにすると可動域が広がる
R2足すり運動3回くらい
ねらい動作の前の“油をさす”ような軽い準備運動。膝・腰を動きやすくする。
準備するもの特になし（イス）
やり方
  1. 座位で足を前後にこする（膝の準備）
  2. 腰は立膝で痛みのない範囲で軽くねじる
デモのコツ座って「すっ、すっ」と足を前後にこすって見せる。力まないことを示す。
声かけ例「油をさすように、すっすっと軽く動かしましょう」
よくある間違い力を入れすぎる → 「軽くでいいですよ」。
注意3回くらいで十分。それ以上は効果が上がらない。
レベル調整痛みのない範囲で
② 筋力増強運動
S1座位　脚の横上げ運動左右10回ずつ
ねらい股関節・骨盤まわりの筋を鍛え、歩行の安定性（体幹の揺れ軽減）を高める。立位のサイドステップと同じ筋群に、座ったまま安全に効かせる。
準備するもの安定したイス
やり方
  1. イスに深く座る（背もたれは使わない）
  2. 座面の両端を軽くつかむ
  3. 片脚をまっすぐ横に持ち上げて戻す
  4. テンポよく左右交互に行う
デモのコツ座ったまま脚を横に「スッ」と上げて戻すのを見せる。上体が傾かないことを示す。
声かけ例「座ったまま、脚を横にスッと上げて戻しましょう」
よくある間違い上体が反対側に傾く → 「まっすぐ座ったまま」と声かけ。
注意股関節に痛みがあれば上げる高さを控えめに。
レベル調整上げる高さ・スピードで負荷調整
S2座位　膝の開閉運動20回めやす
ねらい座位版サイドステップと同じねらいを、より省スペースで行える形で。
準備するもの安定したイス
やり方
  1. イスに座る
  2. 両膝を軽く開いて閉じる
  3. なるべく早く
  4. 慣れたら座面を持たずに行う
デモのコツ座って両膝を「パッ・パッ」と開閉して見せる。肩を揺らさないのを強調。
声かけ例「両膝を開いて閉じて、肩は動かさずに」
よくある間違い体幹・肩が揺れる → 回数か振幅を減らす。
注意最初はゆっくり、徐々に早く。
レベル調整座面を持たずに行うとレベルアップ
S3ボールはさみ運動2〜3秒×5回
ねらい骨盤を安定させ内ももを鍛える。腹圧性失禁の予防・改善にも。
準備するものやわらかいボール
やり方
  1. 仰向けで膝を立てる
  2. 膝の間にボールをはさむ
  3. 潰すように2〜3秒保持
  4. ゆるめる、を繰り返す
デモのコツ膝の間でボールを「ギュー」と潰して2〜3秒止めるのを見せる。息を吐くのを示す。
声かけ例「息を吐きながら、内ももでギューっと2〜3秒」
よくある間違い息を止める → 「吐きながら」と声かけ。
注意太ももの内側に疲労が残れば効いている。
レベル調整保持時間を延ばすと負荷増
S4座位　かかと上げ運動10回めやす
ねらい歩行時の“蹴りだし”を強くし、歩行速度・踵からの接地を改善。座位でも同じ筋群（ふくらはぎ）に効かせる。
準備するもの安定したイス
やり方
  1. イスに座る
  2. 両足のかかとを持ち上げてつま先立ちにする
  3. ゆっくり下ろす、を繰り返す
デモのコツ座ったままかかとをスッと持ち上げて見せる。
声かけ例「座ったまま、かかとをスッと持ち上げましょう」
よくある間違い反動を使う → 「ゆっくり丁寧に」。
注意回数を多くできない運動。疲労に注意。
レベル調整上げた状態で数秒保持すると負荷UP
S5座位ステップ運動（その場足踏み）左右計20回めやす
ねらい歩行時の重心移動・リズムをその場で再現。歩行前の準備にも使える。座位で安全に実施できる。
準備するもの安定したイス
やり方
  1. イスに座る
  2. 腿を高く上げるように左右交互に足踏みする
  3. テンポよく続ける
デモのコツ座ったまま腿を高く上げて足踏みして見せる。
声かけ例「腿を高く上げて、その場で足踏みしましょう」
よくある間違い腿が上がらない → 「もう少し高く」と声かけ、無理はしない。
注意疲労が強く残るなら回数を減らす。
レベル調整上げる高さ・速さで負荷調整
③ 転倒予防運動（足・バランス）
F1タオルギャザー左右各10回
ねらい足の指の筋力を高め“踏ん張り”をつくる。歩行スピード改善にも。
準備するものタオル（＋重り／水入りペットボトル）
やり方
  1. イスに座る
  2. 足の下にタオルを敷く
  3. 足の指でタオルを手前にたぐり寄せる
  4. 負荷は先端に重り
デモのコツ足の指だけでタオルを「くしゃくしゃ」とたぐるのを見せる。
声かけ例「足の指でタオルをたぐり寄せましょう」
よくある間違い足全体を使う → 「指先だけで」。
注意初期は踵が浮いてもよいが徐々に踵をつけたまま。疲労が残りすぎたら回数を減らす。
レベル調整タオル先端の重りで負荷調節
F2ボール踏み前後10往復
ねらい不安定な状態での運動で、足・膝まわりの感覚（受容器）を刺激。
準備するもの小さめのボール（ドッジボールより小）
やり方
  1. イスに座る
  2. 足の下にボールを置く
  3. 逃げないように踏む
  4. 慣れたら踏んだまま前後に動かす
デモのコツボールを踏んで、踏んだまま前後にコロコロ動かして見せる。
声かけ例「ボールを踏んで、そのまま前後にコロコロ」
よくある間違い力みすぎ → 足を捻じらないよう注意。
注意力を入れすぎて足を捻じらない。
レベル調整踏んだまま動かすとレベルUP
F3棒の上で板を動かす前後10往復
ねらい不安定面での運動で足・膝の感覚を刺激。集中力も使う。
準備するもの棒2本・板・目印（ハンコ等）
やり方
  1. 2本の棒の上に板を置く
  2. 板の上の目印を倒さないように前後に動かす
デモのコツ目印を倒さないよう「そーっと」大きく前後に動かして見せる。
声かけ例「倒さないように、ゆっくり大きく」
よくある間違い急に動かして倒す → 最初はゆっくり大きく。
注意神経を非常に使う。底面の大きいものから徐々に小さく。
レベル調整底面を小さくすると難度UP
F4座位　膝伸ばし運動左右各10回
ねらい足あげにつながり、歩行時のつまずきを軽減する。座位でも同じ効果が得られる。
準備するもの安定したイス
やり方
  1. イスに座る
  2. 片膝をゆっくり伸ばす
  3. つま先を天井に向けて2〜3秒保持
  4. ゆっくり戻す
デモのコツ座って片膝を伸ばし、つま先を天井に向けて数秒保持するのを見せる。
声かけ例「膝をゆっくり伸ばして、つま先を天井に向けましょう」
よくある間違い反動をつけて伸ばす → 「ゆっくり」と声かけ。
注意膝に痛みがあれば可動範囲を狭める。
レベル調整保持時間を延ばす、足首に軽い重りをつけると負荷UP
5. 記録すること
  • 実施した種目（区分ごと）と回数・時間
  • 実施時の様子（意欲・ふらつき・疲労の程度）
  • 痛みの有無・部位、中止した場合はその理由
  • 次回への申し送り（レベルを上げる／下げる など）
6. 安全管理・中止の基準
・運動中に痛み（疼痛）が出たら、その運動を中断または中止する。痛みを我慢しての運動は基本的に行わない。
・開始前に体調・気分を確認。体調不良・強い疲労・（必要時）血圧が高いときは行わない。
・本メニューは全11種を座位で実施できるよう設計しています。立位での訓練が必要な場合は、個別プログラム（003・004）で別途検討する。
・回数・負荷・レベルは利用者ごとに、無理のない範囲から。疲労が強く残るなら回数を減らす。
・股関節の人工関節術後など既往のある方は、対象運動の可否を事前に確認する。
